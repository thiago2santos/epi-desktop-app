# Modelagem do fluxo de EPI

Esta pasta organiza a modelagem em tres partes do fluxo operacional:

- `ANTES_DA_ENTREGA.md`
- `DURANTE_A_ENTREGA.md`
- `DEPOIS_DA_ENTREGA.md`

Objetivo: separar claramente as regras e os dados de cada etapa para facilitar evolucao do sistema, validacao com o key user e implementacao incremental.

Cadastro institucional das plantas:

- `unidades-de-implantacao.md` — enderecos das oito unidades da empresa em que o sistema sera implantado.
- `dossie-prospect-access.md` — dossie comercial da Access: quem e, encaixe com o produto e plano da conta.
- `cargos-cbo-operacao-access.md` — cargos com CBO para os testes: planta de guarda da Access e fabrica.
