# Modelagem do fluxo de EPI

Esta pasta organiza a modelagem em tres partes do fluxo operacional:

- `ANTES_DA_ENTREGA.md`
- `DURANTE_A_ENTREGA.md`
- `DEPOIS_DA_ENTREGA.md`

Objetivo: separar claramente as regras e os dados de cada etapa para facilitar evolucao do sistema, validacao com o key user e implementacao incremental.
